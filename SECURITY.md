# Security and sensitive documents

Treat PDF files as potentially untrusted input. This application uses native PDF/OCR components and a Java validator; worker isolation and resource limits are not a complete operating-system security sandbox.

For a vulnerability, use GitHub's **Security → Report a vulnerability** feature when available. Avoid public exploit details, personal documents, credentials, or student data while a report is being assessed. If private reporting is unavailable, open a minimal issue requesting a private contact method without including sensitive details.

No response-time, maintenance, or security-fix guarantee is made. Use a supported operating system, maintain backups, and consider an isolated environment for documents from unknown sources.
